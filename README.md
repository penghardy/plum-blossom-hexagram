# 梅花易数起卦辅助工具 / Plum Blossom Hexagram Calculator

一个基于梅花易数理法的交互式起卦辅助页面。输入三个数字，工具自动完成起卦计算、变卦推演，并展示卦辞、爻辞与象传原文，供研习者参考使用。

## 功能特点

- **起卦计算**：输入三个数字，自动按梅花易数规则计算上卦、下卦与动爻，生成本卦与变卦。
- **卦象可视化**：使用 Canvas 绘制六爻线条，阳爻为实线，阴爻为断线，动爻以红色高亮标记。
- **双卦对照展示**：本卦与变卦并列呈现，主次分明。
- **原文数据展示**：内置《易经》64卦卦辞、384条爻辞及象传原文，供研习者查阅。
- **动爻称呼自适应**：显示动爻在本卦中的称呼，并在变卦后同步更新称呼。
- **三才取数指南**：附"天、地、人"三才取数法说明，帮助理解梅花易数的起卦逻辑。

## 使用方式

1. 在三个输入框中分别填入任意正整数（分别对应上卦、下卦、动爻的取数来源）。
2. 点击"开始占卜"按钮。
3. 页面将自动呈现：
   - 本卦与变卦的卦象图
   - 本卦卦辞与象传原文
   - 动爻原文及变后称呼
   - 变卦卦辞与象传原文
   - 上下卦直接结果（辅助参考）

## 起卦逻辑（梅花易数规则）

- **上卦**：第一个数 ÷ 8 取余（余数 0 视为 8），对应先天八卦（1乾、2兑、3离、4震、5巽、6坎、7艮、8坤）。
- **下卦**：第二个数 ÷ 8 取余（规则同上）。
- **动爻**：第三个数 ÷ 6 取余（余数 0 视为 6），确定第几爻变动。
- **变卦**：本卦动爻阴阳翻转（阳变阴，阴变阳），其余五爻不变，生成新卦。

## 注意事项

- 本工具为**起卦辅助工具**，其功能限于根据输入数字计算卦象并展示《易经》原文与《易传·象传》注释，**不提供占断、解卦或吉凶判断**。
- 卦辞、爻辞均引用自《易经》通行本，象传取自《易传》。原文展示仅供研习者自行参考。
- 若输入非数字或为空，页面会提示校验错误。
- 建议结合《梅花易数》原著及专业研习者的指导进行理解和运用。
